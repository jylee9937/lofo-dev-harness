## 4. Mode: collaborative

- Commit, push, open PRs and merge only when the user asks.
- Never commit directly to `main`. Always create a branch first.
- When a decision is needed, ask one question at a time with the recommended option first. Facts you can check in the code or config, check yourself instead of asking.
- Deploys, hosted database changes and writes to external services need the user's confirmation every time. A confirmation covers only that one action.
