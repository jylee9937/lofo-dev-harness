## 4. Mode: autonomous (coming soon)

Autonomous mode (unattended work in a time window, a decision queue for the owner, and merges after the Codex security gate passes) arrives in a later version of lofo-dev-harness. Until then, the collaborative rules apply.

- Commit, push, open PRs and merge only when the user asks.
- Never commit directly to `main`. Always create a branch first.
- When a decision is needed, ask one question at a time with the recommended option first.
- Deploys, hosted database changes and writes to external services need the user's confirmation every time.
